### 🖼️ 최종 비주얼 목업 사양 요약

**선택된 컨셉:** 컨셉 A (안전함과 신뢰감을 주는 색상 조합)
**핵심 컬러 팔레트:** #6A5ACD (Slate Blue / 연보라 계열 중심) 및 보조 색상으로 화이트, 밝은 회색.
**타겟 감성:** 학부모의 불안감 해소 및 재미있는 학습 경험 제공.

#### 1. 유튜브 썸네일 목업 사양 (YouTube Thumbnail Mockup Specification)

**목표:** 시각적 충격과 신뢰감을 동시에 전달하여 클릭 유도.

| 항목 | 세부 내용 | 적용 값 | 비고 |
| :--- | :--- | :--- | :--- |
| **사이즈** | 1280 x 720 px (권장) | 1280x720 | 표준 유튜브 비율 |
| **배경 색상** | 메인 컬러 기반의 부드러운 그라데이션 | #6A5ACD (중심) $\rightarrow$ #9370DB (보조) | 신뢰감 및 감성 강조 |
| **주요 요소 배치** | 좌측 1/3: 인물 이미지 / 우측 2/3: 핵심 메시지 | 시선 흐름 유도 |
| **폰트 스타일** | 제목: 두꺼운 산세리프체 (Bold) / 후크: 깔끔한 고딕체 | Noto Sans Bold (또는 유사 굵은 고딕) | 가독성 최우선 |
| **텍스트 오버레이 (제목)** | Writer 최종 선택 문구 적용 | [여기에 확정된 제목 입력] | 중앙 상단 배치 권장 |
| **시각적 요소** | 학습의 즐거움(놀이/상호작용)을 암시하는 아이콘 또는 일러스트 삽입. | (예: 밝은 색상의 뇌/별/친구 관련 벡터 이미지) |

#### 2. 인스타그램 포스트 목업 사양 (Instagram Post Mockup Specification)

**목표:** 피드 내에서 시선을 사로잡고 스토리를 전달하여 참여 유도.

| 항목 | 세부 내용 | 적용 값 | 비고 |
| :--- | :--- | :--- | :--- |
| **사이즈** | 1080 x 1080 px (정사각형) | 1080x1080 | 인스타그램 표준 비율 |
| **배경 색상** | 깨끗하고 밝은 느낌 강조 | #FFFFFF (화이트) 또는 아주 연한 그레이 (#F5F5F5) | 정보 전달 명료화 |
| **핵심 디자인 요소** | 브랜드 컬러를 포인트로 사용 | #6A5ACD (텍스트/프레임) | 통일성 유지 |
| **텍스트 오버레이 (후크)** | Writer 최종 선택 문구 적용 | [여기에 확정된 후크 입력] | 중앙에 배치, 충분한 여백 확보 |
| **디자인 레이아웃** | 스토리텔링 구조 강조 | 상단(후크) $\rightarrow$ 중간(핵심 이미지/아이콘) $\rightarrow$ 하단(CTA) | 스크롤 시 집중도 유지 |
| **Call to Action (CTA)** | 명확하고 친근하게 유도 | "지금 시작하기", "더 알아보기" 등 | 버튼 형태로 디자인 |
