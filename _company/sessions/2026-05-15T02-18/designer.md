Writer가 확정한 최종 마케팅 카피를 기반으로, 서비스 런칭에 필요한 유튜브 및 인스타그램용 최종 비주얼 목업(Mock-up)의 디자인 시스템을 완성하고 적용하겠습니다. 모든 시각적 요소는 기존 브랜드 가이드라인(#6A5ACD 중심)과 최적화된 메시지를 통합하여 가장 강력하게 설계됩니다.

---

## 🚀 최종 서비스 런칭 비주얼 시스템 확정 (Final Visual System Specification)

이 문서는 Figma에 즉시 적용할 수 있는, 마케팅 카피와 브랜드 가이드라인이 완벽히 통합된 최종 디자인 명세입니다.

### 1. 브랜드 시스템 재확인 (Brand System Confirmation)

| 요소 | 설정 값 | 비고 |
| :--- | :--- | :--- |
| **주 색상 (Primary Color)** | `#6A5ACD` (Slate Blue) | 신뢰감과 차분함을 부여하는 주조색. |
| **보조 색상 (Accent Color)** | `#FFFFFF` (White) 및 `#F0F8FF` (Alice Blue) | 텍스트 가독성 극대화. 배경은 깨끗하게 유지. |
| **폰트 시스템** | 제목: Pretendard Bold / 본문: Pretendard Regular | 명료함과 모던함을 동시에 추구. |
| **레이아웃 원칙** | '질문'을 최상단에 배치하여 시선 즉시 포착 (Pain Point First). |

### 2. 유튜브 썸네일 목업 디자인 상세 (YouTube Thumbnail Mockup)

**목표:** 최대의 클릭률(CTR) 유도 및 문제 제기.
**적용 카피:** 버전 1 또는 버전 2 중 선택하여 적용.

#### A. [선택된 컨셉 적용 예시: 버전 1]
*   **핵심 메시지:** "⚠️ 우리 아이 영어 말하기 공포증? 영어가 두려워 입을 닫는 이유."

| 레이아웃 영역 | 디자인 상세 지침 (Coordinates/Elements) | 스타일 적용 |
| :--- | :--- | :--- |
| **배경** | 전체 배경: `#6A5ACD` (짙은 블루 계열)로 설정. | Full Screen |
| **메인 텍스트 (Hook)** | "우리 아이 영어 말하기 공포증?" | **폰트:** Pretendard Bold, 크기: 72pt 이상, 색상: `#FFFFFF` |
| **서브 텍스트 (Focus)** | "영어가 두려워 입을 닫는 이유." | **폰트:** Pretendard Bold, 크기: 50pt 내외, 색상: `#F0F8FF` (밝은 블루) |
| **강조 요소** | '⚠️' 이모지 또는 경고 아이콘을 메인 텍스트 앞에 배치. | 시각적 충격 극대화 |
| **브랜드 로고/뱃지** | 우측 하단에 작게 `회홧몬` 워터마크 배치. | 색상: `#FFFFFF`, 투명도 50% |

#### B. [선택된 컨셉 적용 예시: 버전 2]
*   **핵심 메시지:** "초등학생, 영어를 '말'하는 법! (발음/문법 불안 끝)"

| 레이아웃 영역 | 디자인 상세 지침 (Coordinates/Elements) | 스타일 적용 |
| :--- | :--- | :--- |
| **배경** | 상단 1/3: `#6A5ACD`, 하단 2/3: `#FFFFFF` 그라데이션 또는 분할. | 대비 효과 극대화 |
| **메인 텍스트 (Hook)** | "초등학생, 영어를 '말'하는 법!" | **폰트:** Pretendard Bold, 크기: 60pt, 색상: `#6A5ACD` |
| **서브 텍스트 (Solution)** | "(발음/문법 불안 끝)" | **폰트:** Pretendard Bold, 크기: 45pt, 색상: `#6A5ACD` |
| **강조 요소** | '말' 부분에 강조를 위해 볼드체 또는 작은 박스 처리. | 학습 요소 부각 |

### 3. 인스타그램 포스트 목업 디자인 상세 (Instagram Post Mockup)

**목표:** 공감 유도 및 행동 촉구(Call to Action).
**적용 카피:** "🤔 '영어는 어려워요'가 입버릇이 된 아이에게 필요한 건? ✨"

| 레이아웃 영역 | 디자인 상세 지침 (Coordinates/Elements) | 스타일 적용 |
| :--- | :--- | :--- |
| **이미지 구도** | 중앙에 큰 질문 텍스트를 배치하고, 주변 여백을 충분히 확보하여 심리적 안정감을 제공. | 미니멀리즘 추구 |
| **배경 이미지** | 깨끗한 `#FFFFFF` 배경 또는 은은한 그라데이션 (`#F0F8FF`) 사용. | 깔끔함 유지 |
| **메인 텍스트 (Hook)** | "🤔 '영어는 어려워요'가 입버릇이 된 아이에게 필요한 건?" | **폰트:** Pretendard Bold, 크기: 55pt 이상, 색상: `#6A5ACD` |
| **강조 요소** | 질문 앞에 ✨ 이모지를 배치하여 긍정적이고 희망적인 분위기 조성. | 감성적 연결 강화 |
| **CTA 영역** | 이미지 하단에 서비스명(`회홧몬`)과 간결한 CTA를 별도 박스 처리. | 명확한 행동 유도 |
